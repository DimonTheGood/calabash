# Мувмент Ждана (в духе ULTRAKILL)

Контроллер героя от первого лица для Unity 6 (URP, Input System): быстрый бег,
сильный контроль в воздухе, дэш на стамина-зарядах, слайд, слайд-прыжок,
граунд-слэм с отскоком, прыжки от стен, койот-тайм и буфер прыжка.

Папка — самодостаточный модуль Unity: её копируют в `Assets/` любого проекта.

## Подключение

1. Скопируйте папку `movement/` в проект Unity как `Assets/Calabash/Movement/`
   (вместе с `.meta`-файлами, чтобы сцена и префаб не потеряли ссылки).
   ```bash
   cp -r movement <UnityProject>/Assets/Calabash/Movement
   ```
2. Нужны пакеты **Input System** и (для материалов) **URP** — в шаблоне Unity 6 URP 3D они уже есть.
   Со старым Input Manager ввод переключается сам по `ENABLE_INPUT_SYSTEM`, но этот путь пока не проверялся.
3. Откройте `Assets/Calabash/Movement/Scenes/MovementTest.unity` и нажмите Play.
   Сцены нет или её надо пересобрать — меню **Calabash → Movement → Собрать тестовую сцену**.

### Свой уровень

Перетащите префаб `Prefabs/Zhdan_FPS.prefab` в сцену (пивот в ногах) и удалите
другие камеры с тегом MainCamera. В префабе:

| Объект | Компоненты |
|---|---|
| `Zhdan_FPS` | CharacterController, `ZhdanInput`, `ZhdanMovement`, `FirstPersonLook`, `MovementHud`, `TestRespawn` |
| `└ CameraPivot` | шарнир тангажа на высоте глаз, его опускает слайд |
| `   └ Main Camera` | Camera, AudioListener, `ZhdanCameraFx` |

`MovementHud` и `TestRespawn` нужны только для отладки, их можно удалить.

Собрать героя вручную: CharacterController (radius 0.4, height 1.8, center (0, 0.9, 0),
skin 0.06, slope 50, step 0.35) + `ZhdanInput` + `ZhdanMovement` + `FirstPersonLook`
с дочерним шарниром и камерой на нём.

## Управление по умолчанию

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Бег | WASD | левый стик |
| Обзор | мышь | правый стик |
| Прыжок; у стены — прыжок от стены | Space | A / South |
| Дэш (по направлению ввода, без ввода — вперёд) | Left Shift, Mouse 4 | RB |
| Слайд на земле; в воздухе — граунд-слэм | Left Ctrl или C | B / East |
| Респаун (тестовая сцена) | R | — |
| Показать/скрыть HUD | F1 | — |
| Отпустить/захватить курсор | Esc / ЛКМ | — |

Клавиши переназначаются в инспекторе `ZhdanInput`.

## Механики

- **Бег**: 12 м/с, разгон почти мгновенный. Скорость сверх бега (после слайд-прыжка)
  на земле гасится плавно.
- **Воздух**: вектор скорости быстро поворачивается к вводу, набранная скорость
  не срезается, а медленно стекает (`airOverspeedDecay`). Гравитация 40 м/с², как в ULTRAKILL,
  сильнее земной.
- **Дэш**: горизонтальный рывок 45 м/с на 0,18 с, стоит 1 заряд из 3, заряды
  восстанавливаются (0,9 в секунду). Первые 0,2 с герой неуязвим (`IsInvulnerable`).
  Дэш прерывает слэм и слайд.
- **Дэш-прыжок**: прыжок с земли во время дэша — 30 м/с по горизонтали за ещё 1 заряд.
- **Слайд**: присед на земле. Скорость = max(20, текущая + 4), потолок 42 м/с, без трения
  на ровном, на спуске разгоняет, на подъёме тормозит. Хитбокс 0,9 м, камера опускается.
  A/D подруливают. Под низким потолком слайд не кончается, пока не встанешь.
  Если Ctrl зажат при приземлении или в конце дэша, слайд начинается сразу.
- **Слайд-прыжок**: прыжок из слайда сохраняет всю горизонтальную скорость.
- **Граунд-слэм**: Ctrl в воздухе (выше 0,8 м над землёй) — удар вниз со скоростью 90 м/с.
  После приземления 0,25 с окно: прыжок даёт отскок 20 м/с + 0,4 м/с за каждый метр
  падения (до 36). Событие `onSlamLand(высота)` — точка для ударной волны.
- **Прыжки от стен**: до 3 до приземления. Отталкивают от стены и вверх и сохраняют
  60 % скорости вдоль стены. Если давить в стену в воздухе, герой медленно сползает (5 м/с).
- **Койот-тайм** 0,12 с после схода с края и **буфер прыжка** 0,15 с до приземления.
  Буфер работает и для отскока от слэма.

## Параметры

Все числа — публичные поля `ZhdanMovement` с подсказками в инспекторе, по разделам:
Бег, Воздух, Прыжок, Дэш и стамина, Дэш-прыжок, Слайд, Граунд-слэм, Стены,
Хитбокс и земля. Ощущение камеры (FOV от скорости, крен в слайде, тряска от слэма,
высота глаз) настраивается в `ZhdanCameraFx`, чувствительность мыши — в `ZhdanInput`.

Для звуков и VFX есть UnityEvent-хуки `onJump`, `onWallJump`, `onDash`, `onSlideStart`,
`onSlideStop`, `onSlamStart`, `onSlamLand(float)` и `onLand(float)`. Для HUD и ИИ
состояние читается через свойства `State`, `Velocity`, `Stamina`, `WallJumpsLeft`,
`IsInvulnerable`. Внешний толчок — `AddImpulse`, телепорт — `Teleport`.
Для боёвки ([`combat/`](../combat/README.md)) есть `Lunge` (рывок без стамины),
`SetVelocity` (отдача), `RefundStamina` и `speedMultiplier` (замедление при замахе).
`ZhdanInput.ReadCombat()` читает ЛКМ/ПКМ и триггеры геймпада.

## Как тестировать

**Руками** — сцена `MovementTest` (полигон в палитре style bible):

| Зона | Что проверить |
|---|---|
| Старт, прямая с вехами каждые 10 м | бег, дэш; скорость видна в HUD |
| Колонны позади старта (развернитесь) | дэши между колоннами, 3 заряда, восстановление |
| Склон 15° слева | слайд вниз разгоняется, вверх тормозит |
| Две платформы с пропастью 14 м впереди | слайд → прыжок перелетает, обычный прыжок — нет |
| Туннель 1,3 м справа | проходится только слайдом, внутри герой не встаёт |
| Шахта и вышка 8 м справа | 3 прыжка от стен; с вышки — слэм и отскок |
| Полка 6 м у вышки | залезть отскоком от слэма |

**Автоматически** — меню **Calabash → Movement → Запустить самотест**. Без Play Mode
он прогоняет 26 проверок всех механик (бег, воздух, слайд, слайд-прыжок, дэш и стамина,
дэш-прыжок, слэм и отскок, прыжки от стен и лимит, койот-тайм, буфер, туннель)
и пишет PASS/FAIL в Console. Из консоли:

```bash
Unity -batchmode -nographics -projectPath <UnityProject> -executeMethod Calabash.Movement.EditorTools.MovementSelfTest.RunBatch -logFile -
```
