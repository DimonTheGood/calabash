## Три правила, которые нельзя нарушать

1. **Цвет — это информация, а не декор.** Серое = мир, оранжевый = огонь,
   красный = смерть, голубой = вода (повышенный урон). Точка.
2. **У живых нет лица.** Лицо появляется только в момент смерти, на панель.
3. **Силуэт читается в 64 px.** Не читается — переделывать.

## Что нужно от геймдизайнера, чтобы двигаться дальше

1. **Ракурс камеры** (2D сбоку / top-down / 3D-стилизация). Без этого нельзя
   начать рисовать ГГ — зависят пропорции и набор анимаций.
2. **N% (порог прохождения)** и **общее число жертв на уровне** — от этого
   зависят стадии тления (они привязаны к проценту, не ко времени).
3. **Есть ли уникальные жертвы на аренах или только массовка?** Если на арене
   только массовка — приоритет отрисовки меняется.
4. **Длительность забега** (один уровень ~5 мин или вся игра ~40 мин?).
