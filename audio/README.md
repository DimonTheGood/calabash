# Звук

Звуки ударов, шагов, огня, врагов и боевая музыка. Все звуки взяты из бесплатных ассетов CC0
с OpenGameArt; откуда какой файл, написано в [`Sounds/LICENSE.txt`](Sounds/LICENSE.txt).

## Что звучит

| Событие | Звук |
|---|---|
| Замах (ЛКМ, «Кувалда», апперкот, таран) | свист, у тяжёлых ниже и с треском огня |
| Попадание | лёгкий или тяжёлый удар; «Кувалда» с полным замахом добавляет взрыв |
| Убийство | вспышка огня |
| Шаги, слайд, приземление | снег под ногами, громче на бегу и при падении с высоты |
| Прыжок | шорох одежды |
| Дэш | свист и вспышка огня |
| Удар оземь | взрыв, тяжёлый удар, огонь |
| Огонь на теле | треск по кругу, громче с топливом и на замахе |
| Урон по Ждану | глухой удар; вода — всплеск |
| Враги | стоны от ударов, крики смерти, свист копья, звон ведра, тетива, стрела в дереве |
| Музыка | играет всегда, громче во время волны |

Удары звучат по-разному: из банка берётся случайный клип (не тот же, что в прошлый раз),
с разбросом высоты и громкости. Звук идёт в реальном времени, поэтому его слышно и во время стоп-кадра.

## Подключение

1. Скопируйте папку с `.meta`-файлами в `Assets/Calabash/Audio/`.
   ```bash
   cp -r audio <UnityProject>/Assets/Calabash/Audio
   ```
2. Пересоберите сцены: **Calabash → Combat → Собрать тестовую арену** и
   **Calabash → Village → Собрать сцену деревни**.

Сборщики вызывают `CalabashAudioSetup.Setup(player)`. Эта функция:
- настраивает импорт: короткие звуки в памяти и в моно, музыка и треск огня потоком;
- создаёт объект `Audio` с `CalabashSfx` (банки звуков) и `CalabashMusic`;
- вешает `ZhdanSfx` на героя.

## Как звучать из своего кода

```csharp
CalabashSfx.Play("punch_heavy", точка);        // в мире
CalabashSfx.Play2D("swing", 0.8f, 1.2f);         // у уха: громкость, высота
CalabashMusic.Combat = true;                     // музыка громче
```

Банк — это все файлы `Sounds/<банк>_NN.ogg`. Чтобы добавить звук, положите файл с новым номером
и пересоберите сцену. Громкость, разброс высоты и долю 3D задаёт таблица `Defaults` в
`Editor/CalabashAudioSetup.cs`, а в сцене их можно поправить в инспекторе `CalabashSfx`.

Банки: `punch_light`, `punch_heavy`, `hurt_hit`, `swing`, `footstep_snow`, `land`, `splash`,
`explosion`, `fire_burst`, `metal_clank`, `blade`, `wood_hit`, `bow_release`, `cloth`, `grunt`, `death`.
Плюс `fire_loop` (треск на герое) и `music_battle`.

## Как пересобрать звуки

Скачайте архивы из `Sounds/LICENSE.txt` и распакуйте их в одну папку. Файлы `.7z` тоже нужно распаковать.
Отдельные файлы (`fire.wav`, `fire-1_0.ogg`, `death_pain_grunts.wav`, `explosion_dull.flac`,
`battleThemeA.mp3`) положите туда же. Затем запустите:

```bash
python3 audio/tools/make_sounds.py <папка>
```

Нужны `numpy` и `soundfile`.
