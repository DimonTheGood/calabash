# «Мрак» — манга-фильтр для Unity

Полноэкранный эффект URP, который делает картинку игры похожей на рендеры
[`village/renders`](../village/renders/village_low.png):

- тон сжат в бумагу, точечный растр под 45°, штриховку и перекрёстную штриховку, самое тёмное уходит в тушь;
- контур тушью по разрывам глубины и изломам поверхности, вдали он бледнее, а край немного неровный, как от кисти;
- небо и туман серые, в растр, по небу идут белые рваные полосы ветра (они привязаны к направлению взгляда, а не к экрану);
- косые штрихи летящего снега, виньетка, зерно;
- насыщенные цвета (огонь, кровь, вода, оранжевый контур Ждана, свет в окнах) остаются цветными, как требует style bible.

**G** в игре включает и выключает эффект.

## Подключение

1. Скопируйте папку с `.meta`-файлами в `Assets/Calabash/Style/`.
2. Меню **Calabash → Мрак → Подключить к URP**. Это добавит проход `MangaGloom`
   (Full Screen Pass, перед пост-обработкой, с глубиной и нормалями) во все Universal Renderer Data в `Assets/`.
3. Выберите камеру и запустите **Calabash → Мрак → Добавить на выбранную камеру**.
   Сборщик деревни (**Calabash → Village → Собрать сцену деревни**) делает это сам.

Без компонента `MangaGloom` на камере проход ничего не меняет, поэтому другие сцены выглядят как раньше.

## Настройки

Все параметры — поля компонента `MangaGloom` с подсказками, их можно крутить прямо в Play Mode:

| Группа | Что меняет |
|---|---|
| Тон | чёрная и белая точки, гамма (больше — мрачнее), тон бумаги |
| Растр | шаг сетки точек, сила, с какого тона появляются точки, тон точки |
| Штриховка | шаг линий, сила, тон начала косой и перекрёстной штриховки |
| Контур тушью | толщина, чувствительность к глубине и нормалям, ослабление вдали, неровность |
| Небо и даль | туман из настроек сцены, насколько темнеют небо и даль, число, толщина и волнистость полос |
| Снег штрихами | сила, наклон, скорость, плотность |
| Кадр | виньетка, зерно, порог насыщенности для цветных пикселей |

Размеры узоров заданы в пикселях для экрана высотой 1080 и масштабируются под разрешение.
