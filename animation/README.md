# Анимации: Ждан, его руки и жители деревни

Риг и анимации для героя и NPC из [`characters/`](../characters/README.md).
Работает поверх [`movement/`](../movement/README.md) и [`combat/`](../combat/README.md).

- **Ждан** в третьем лице бегает, прыгает, скользит, делает дэш и слэм. Удары играются
  поверх бега, только верхней половиной тела.
- **Руки в кадре** от первого лица заменяют кубы-кулаки: плечо, предплечье и сжатый кулак.
  Двухзвенная IK тянет их к кулакам из `ZhdanFistsView`, поэтому замах, удар, бег и слайд
  работают как раньше.
- **Жители деревни** ходят, болтают, молятся и стоят на посту. Их можно бить: они вздрагивают
  и отлетают, жители убегают, а стража поворачивается к Ждану. Если сбить здоровье до нуля,
  житель падает, лежит 4,5 с и встаёт с полным здоровьем.

## Подключение

1. Сначала подключите `movement/`, `combat/` и `style/` (см. их README).
2. Скопируйте эту папку с `.meta`-файлами в `Assets/Calabash/Animation/`. Папку `blender/`
   копировать не нужно.
   ```bash
   rsync -a --exclude blender animation/ <UnityProject>/Assets/Calabash/Animation/
   ```
3. Пересоберите сцены: **Calabash → Village → Собрать сцену деревни** и
   **Calabash → Combat → Собрать тестовую арену**.

Сборщики сами найдут FBX по имени (`SK_Char_hero`, `SM_Zhdan_FPArms`, `SK_Char_<id>`) и выполнят
всю настройку:
- импорт: риг Generic, клипы по именам, зацикленный бег и стойка;
- контроллеры `Controllers/AC_*.controller` и маска `AM_UpperBody.mask`;
- палитру материалов и оранжевый контур героя;
- замену статичной модели Ждана анимированной, а кубов-кулаков — руками.

Если моделей нет, сцены собираются как раньше: статичный Ждан, кубы-кулаки и манекены вместо жителей.

## Ждан

`ZhdanAnimator` каждый кадр выбирает состояние нижнего слоя по `ZhdanMovement`:

| Состояние | Когда | Клипы |
|---|---|---|
| Locomotion | на земле | Idle → Walk → Run по скорости; быстрее 9 м/с бег ускоряется |
| Air | в воздухе | Jump → Fall по вертикальной скорости |
| Slide / Dash / Slam | соответствующий приём | одноимённые |

Верхний слой (от поясницы вверх) — удары: Jab_L, Jab_R, Hook_R, Heavy, DashStrike, Uppercut.
Клип удара не проигрывается сам. `ZhdanAnimator` перематывает его по фазе удара
из `ZhdanCombat`, поэтому кулак в клипе всегда долетает в момент попадания. Разметка каждого
клипа удара: 0–0,3 замах, 0,3–0,5 удар, 0,5–1 возврат в стойку. Пока заряжается «Кувалда»,
клип стоит в замахе.

`ZhdanBodyView` с анимированной моделью только слегка наклоняет тело на бегу и в дэше.
Остальное делают клипы.

## Руки от первого лица

`ZhdanArmsView` висит под камерой (`FPArms`). Основные поля:

| Поле | По умолчанию | Что делает |
|---|---|---|
| `shoulder` | (0,21, −0,38, −0,02) | плечо относительно камеры |
| `scale`, `thickness`, `fistScale` | 1,25 / 1,5 / 1,2 | руки крупнее и толще настоящих, как в доке |
| `elbowHint` | (0,8, −1, −0,2) | куда смотрит локоть |
| `fistRoll` | 60° | поворот кулака вокруг предплечья |
| `fistInset` | 0,03 м | насколько кулак заходит в предплечье |

Если кулак улетает дальше длины руки (таран, размах), плечо подаётся за ним.
Руки видны только в первом лице: `ZhdanCameraMode.firstPersonOnly`.

## Жители

`VillagerNpc` — кинематический житель: своя гравитация, без Rigidbody. Он стоит на земле
и упирается в стены. Удар толкает его на `knockback / mass`.

| Роль | Поведение | Пугается |
|---|---|---|
| Wanderer | ходит по точкам или бродит вокруг места появления | да |
| Talker | стоит и разговаривает (Talk) | да |
| Prayer | молится (Pray) | да |
| Stander | просто стоит | да |
| Guard | стоит на посту, после удара поворачивается к Ждану | нет |
| Patrol | ходит дозором по точкам | нет |

Пугливые жители закрываются руками (Cower), если Ждан бьёт ближе 4 м. После удара они убегают.
Сбитые с места постовые возвращаются на место.

В деревне сборщик ставит 6 мирных жителей:
- у колодца разговаривают Гаврила с крестьянином;
- Агафья молится, поп Никодим стоит рядом и говорит;
- бродят Ефим и крестьянин.

Стража, лучник, ведровой и палач Корней — враги: их волнами выводит [`enemies/`](../enemies/README.md).

Точки — в `VillageSceneBuilder.PlaceVillagers`.

Клипы жителей: Idle, Walk, Run, Talk, Pray, Cower, Hit, Death, GetUp.

Атаки врагов (есть у всех жителей): замах до 40% клипа, удар — 40–55%, дальше возврат.

| Клип | Что делает | Кто |
|---|---|---|
| Thrust | выпад обеими руками с шагом вперёд | мужик с вилами |
| Chop | руки над головой, удар вниз с поклоном | стражник (копьё), палач Корней |
| Throw | бросок из-за головы правой рукой | ведровой |
| Shoot | боком к цели, лук вперёд, тетива к щеке, выстрел | лучник |

## Как пересобрать модели (Blender 4.5)

```bash
blender -b --factory-startup -P animation/blender/rig_characters.py -- animation
```

Скрипт берёт геометрию из `characters/scripts/build_characters.py`. Этот файл только читается,
поэтому модели совпадают с концептами. Затем скрипт:
- ставит риг из 21 кости;
- скинит тело тепловыми весами, одежду — с ослабленным влиянием ног, жёсткие предметы — целиком на одну кость;
- создаёт клипы;
- выгружает `fbx/SK_Char_*.fbx` и `fbx/SM_Zhdan_FPArms.fbx`.

Опции:
- `--only=hero,peasant` — только выбранные персонажи;
- `--fp-arms` — только руки от первого лица (быстро и почти без памяти);
- `--preview=<папка>` — кадры поз для проверки.
- `--fist=<вариант>` — вид кулаков в руках от первого лица, по умолчанию `charred`: `base` (старые), `wrapped` (бинты),
  `charred` (обугленные, с трещинами-углями), `brawler` (крупные, тяжёлые), `bound` (верёвка с костра
  на запястьях). Во всех, кроме `base`, кулак собран по пальцам, большой палец прижат;
- `--fp-preview=<папка>` — вместе с `--fp-arms`: вместо FBX два кадра рук (вид из глаз и крупно).

Полная пересборка занимает несколько минут. Если не хватает памяти, закройте Unity
или собирайте персонажей по одному через `--only`.

## Файлы

```
Scripts/ZhdanAnimator.cs      — Animator Ждана ← мувмент и бой
Scripts/ZhdanArmsView.cs      — руки в кадре, двухзвенная IK
Scripts/VillagerNpc.cs        — поведение и удары по жителям
Editor/CharacterAnimSetup.cs  — импорт FBX, контроллеры, герой, жители
blender/rig_characters.py     — риг, скиннинг, клипы, экспорт
fbx/                          — SK_Char_hero, 12 персонажей, SM_Zhdan_FPArms
Controllers/, Materials/      — сгенерированы сборщиком
```

## Что пока временное

- Клипы сделаны процедурно, ключевыми позами. Для финала их стоит заменить ручной анимацией
  с теми же именами.
- Жители не обходят препятствия: упёршись, они идут к следующей точке.
- Король, Тень и Лимбо выгружены с ригом, но в деревню не поставлены.
